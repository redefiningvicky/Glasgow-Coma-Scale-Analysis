<a name="objective"></a>
<h2>🎯 Objective</h2>

<p>
  This project analyzes the Glasgow Coma Scale (GCS) scores
  for distribution, share, and severity of patient acuity
  in California for 2024. Using California Department of
  Health Care Access and Information (HCAI) hospital
  inpatient data, the interactive Tableau Viz illustrates
  the state's clinical acuity profile.
</p>
